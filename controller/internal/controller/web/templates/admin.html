Add alongside

Create a new HotSpot server on an interface that has none, and Adopt it. The HotSpot servers already on the Router are not changed.

{{with .AddAlongside}}{{if .Interfaces}}

Suggested: the next private range of the same size that overlaps nothing on the Router. The Controller adds the address, an address pool, a DHCP server, a server profile, the HotSpot server and a NAT exemption so its Devices reach the Portal.

{{else}}
