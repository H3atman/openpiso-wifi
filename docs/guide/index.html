Open source piso WiFi

Sell WiFi time by Voucher on your MikroTik, today.

OpenPiso WiFi turns a small Linux board into the Controller for your Shop, the place you sell WiFi time. It prints Vouchers (codes worth a fixed amount of time), keeps the record of the time each customer bought, and tells your MikroTik Router who may go online. Coin Vendos are coming.

Read the guide See it on GitHub

Early release. OpenPiso WiFi is new and still changing. If something does not work, please tell us on GitHub Issues.

Install

On the board, over SSH. This example is for an Orange Pi Zero at 192.168.10.2; the Guide explains each value.

base=https://github.com/H3atman/openpiso-wifi/releases/latest/download
curl -fLO "$base/openpiso-linux-armv7"
curl -fLO "$base/openpiso-install.tar.gz"
tar -xzf openpiso-install.tar.gz
cd install
sudo sh install.sh --binary ../openpiso-linux-armv7 \
  --portal-url http://192.168.10.2 \
  --admin-network 192.168.10.0/24

How it works

Three parts, on the network you already have.

  1. Controller

    A small Linux board, such as an Orange Pi Zero. It keeps the record of every customer's time, serves the Portal (the page a phone opens when it joins your WiFi) and runs the admin panel where you set prices and print Vouchers.

  2. Router

    Your MikroTik, with the HotSpot server it already runs. It lets customers online and counts the time they use, on the Controller's instructions.

  3. Vendo coming

    A coin-accepting unit on your network, built on an ESP8266 coin board, that reports each coin to the Controller. The customer drops a coin and gets time, just like a Voucher. The Guide for setting one up is coming.

What you need

A board for the Controller

Tested on an Orange Pi Zero with Armbian. Should work on Raspberry Pi OS Lite, or any arm64 or amd64 Linux with systemd. Plus a microSD card and a network cable.

A MikroTik Router

RouterOS v7, a HotSpot server your customers already join, and www-ssl turned on with a certificate. The Guide shows how to make one.

A PC and a printer

A Windows PC on the same network to set things up, and a printer, or a PDF, for your Vouchers.
